# Triage Labels

| Role | Label | Description |
|------|-------|-------------|
| Needs Triage | `needs-triage` | New issue, not yet reviewed |
| Needs Info | `needs-info` | More information required before action |
| Ready for Agent | `ready-for-agent` | Spec is clear, ready for AI implementation |
| Ready for Human | `ready-for-human` | Requires human developer attention |
| Wontfix | `wontfix` | Acknowledged but will not be addressed |
